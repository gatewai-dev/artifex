# LLM

## What It Does
Sends a text prompt, an optional developer/system instructions prompt, and optional images to a state-of-the-art Large Language Model (such as **GPT-5.6**, **Gemini 3.5**). It returns the generated text answer. The node is multimodal, allowing you to feed images directly into the chat context to perform image description, analysis, or extraction tasks.

## When to Use
- **Text Generation:** Write video descriptions, dialogue scripts, marketing copy, or summarize text.
- **Multimodal Visual Analysis:** Feed a generated image or frame into the LLM alongside a prompt like "Extract all text from this sign" or "Write a social media caption describing the mood of this photo."
- **Structured Data Extraction:** Generate clean JSON, lists, or custom-formatted strings from input transcripts or descriptions.

## Inputs
| Handle | Type | Required | Description |
|--------|------|----------|-------------|
| Prompt | Text | ✅ | The main prompt or question for the LLM. |
| System Prompt | Text | ❌ | High-priority system instructions detailing the persona, style constraints, or response format rules for the AI. |
| *Variable Inputs* | Image | ❌ | Connect one or more images to enable multimodal vision/Q&A capabilities. |

## Config
| Field | Type | Range | Default | Description |
|-------|------|-------|---------|-------------|
| model | string (enum) | `openai/gpt-5.6-terra`, `openai/gpt-5.6-luna`, `openai/gpt-5.6-sol`, `google/gemini-3.7-flash`, `x-ai/grok-4.5`, | `"openai/gpt-5.6-luna"` | The LLM model to query. |
| reasoningEffort | string (enum) | `none`, `low`, `medium`, `high`, `xhigh` | `"medium"` (OpenAI only) | Controls the scale of the model's internal thinking/reasoning before generating the final text. |
| textVerbosity | string (enum) | `low`, `medium`, `high` | `"medium"` (OpenAI only) | Tells the model whether to generate a concise or detailed response. |
| temperature | number | 0.0 to 2.0 | undefined | Creativity setting. *Supported only when reasoningEffort is not set or set to `none`.* |

## Output
| Handle | Type | Description |
|--------|------|-------------|
| Result | Text | The text response generated by the model. |

## Common Patterns
- **Vision Translation / Captioning:**
  `Import (Image) → [Connect to Image input handle of LLM] + Prompt ("Describe this image in detail") → LLM → Output Text`
- **Agent Persona Setting:**
  - `System Prompt: "You are a screenwriting assistant. Output ONLY dialog scripts."`
  - `Prompt: "Write a short dialog about two space explorers discovering an alien artifact."`

## Limitations & Pricing
- **Pricing:** Flat rate charged per invocation depending on the selected model:
  - `openai/gpt-5.6-luna`: **3 credits**
  - `openai/gpt-5.6-terra`: **4.5 credits**
  - `openai/gpt-5.6-sol`: **9 credits**
  - `google/gemini-3.7-flash`, `x-ai/grok-4.5`: **3 credits**
- **Temperature & Reasoning conflict:** For OpenAI models, temperature is ignored if reasoning (chain-of-thought) is active (set to low, medium, high, or xhigh). To use a custom temperature, set `reasoningEffort` to `none`.
